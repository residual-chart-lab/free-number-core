# 一般にどこまで成立するか：証明をまとめる

FN-GENERAL-PROOFS-001 v0.1 / 2026年11月6日。アキの「これまで流していた一般に取れるところを取る」という依頼に基づく研究記録（公開用案内）。

**有限の成功例から、条件付きの一般命題へ進めた。** 16項目について対象・前提・結論・証明を書き、計算例と区別した。既知の定理やCoreで既に証明済みの部分は、その出所を残している。

公開時の帰属補足：任意長の応答復元は固定Coreの既存成果。今回の再導出・評価式・接続との関係は [Coreとの関係](../CORE_RELATIONSHIP.md) を参照。

## 大きい到達点

1. **運び方を、一本の軸から三次元の全ての残差形状へ広げた。** 固有値の重なり方が変わらない区間なら、今の残差とその変化を受け取って各固有空間を追う規則は、共通の座標回転に整合させることで一意に絞れる。線形性や最小ノルムを前提にしない。最小ノルムの構成そのものは、任意次元の対称行列へ拡張した。
2. **任意の有限長の四元数の列を表すテンソルで、全てのすき間への応答からそのテンソルを復元する式を得た。** 帰納法で証明した。純虚数の因子からなるCore型の列では、プローブも純虚数だけに制限でき、3^(m-1)個の四元数評価で復元できる補題も得た。因子の分け方や原文履歴の復元とは区別し、記録量は長さとともに増える。Coreの許容操作へ全て追加した、または長さ2の記録で任意の長い履歴が分かる、という意味ではない。
3. **スピン1の結果を一般のスピンへ広げた。** 今回の二次結合は、スピン0・1/2では残差を区別せず、スピン1以上では必ず区別する。一般係数の式も証明した。
4. **指定接続での運搬は、任意の有限経路と合成へ通る。** 二つの小さな閉路だけに依存しない代数的証明を記した。
5. **ローターとKK側も、指定した数例を越える一般式を確認した。** 仕事・エネルギー・角運動量の収支、単位換算、任意の指定背景でのKK縮約と逆向きの持ち上げを証明した。

そして、四次元では同じ一意性条件だけでは不足する例、固有値が衝突すると連続に延長できない例、端点だけでは局所座標の運搬を決められない一般的な障害も命題として固定した。

## 証明と計算の区別

一般命題は文中の代数・帰納法・対称性・変分による論証で支える。`checker.py`の有限検査件数を一般証明の代用にしない。証明支援系による形式検証は今回行っていない。

実装は標準Pythonだけを使う。長さ1〜4の全応答行列、次元2〜5の対称行列、スピン0〜3の六種類、位置に依存するKK背景と二次のゲージ変換などを有理数で検査した。スピンの実装は平方根を避ける非正規化多項式基底を使い、ランクとトレースという基底に依存しない量を照合する。新しい物理軌道を数値積分した検査ではない。

```text
python -I -B checker.py --out fresh-output
```

結果は`run/RESULTS.json`、詳細は`run/EXACT_CERTIFICATES.json`。実行環境表示を除き、再実行で照合できる。一般式の入力域と、旧有限リンクのFractionの算術制約は分けている。
