# 自由数 — 2026年11月6日の、もう一つの贈り物

**本体は固定Core v1.0.0。その上に、一般証明16項目＋二追補と、動く応用例を添えて渡す。**

アキが問いを立て、ロニーが模型と証明をまとめ、Astraが独立に検討・検算した研究配布。MITで改変・再配布できる。

## 何を受け取れるか

1. **変えない本体。** [Free Numbers Core v1.0.0](https://github.com/residual-chart-lab/free-number-core/releases/tag/core-v1.0.0)。既存の固定版とDOIをそのまま参照する。
2. **今回の証明束。** 16項目について前提と証明を記した英語本文、純虚プローブと全次元rank-one分類の二追補。独立監査、初稿の反例、訂正、検算コード、保存結果も含む。
3. **自由数の使い方。** KKから着想を得た指定接続に沿う残差輸送と、残差応答の変化から条件付きで運搬規則を構成する二つの有限模型。

まず何を試したいかで選んでよい。同じ終点でも途中への操作で違いが出る例は `examples/connection-holonomy/`。運び方を残差から作る例は `examples/generated-transport/`。一般の成立範囲を読みたいなら `proofs/01_...` から `05_...` へ進む。

**任意長の応答復元そのものは、すでに固定Coreの成果に含まれる。** 今回の再導出・評価式・運搬への接続と分けて扱う。[Coreとの関係](CORE_RELATIONSHIP.md)を参照。16項目は16件の新発見という数え方ではない。

## 手元で動かす

Python 3.12以上。通常の検算には追加ライブラリーもネット接続も不要。ZIPを展開したフォルダーで次を実行する。

```text
python -I -B verify_manifest.py
python -I -B run_checks.py --out fresh-checks
```

保存済み結果を上書きしないよう、出力先は毎回新しい名前にする。主29検査、二追補、訂正式、Astraの独立35＋18検査と応用の独立81検査、応用36＋65検査を実行する。検査の件数と一般証明は別であり、成立範囲は各証明の前提を読む。

## 監査と訂正を一緒に残す

Astraの最終判断は、明記した仮定のもとで主16項目と二追補がPASS。初稿のF01は、単軸行列の振幅を求める補助式で中心化を欠いた問題だった。`diag(2,1,1)`という反例、旧本文、訂正差分、修正確認を同梱した。旧稿の誤りを消して成功履歴へ書き換えない。

監査済みの証明本文と計算ソースはバイト一致で保持した。公開用の監査・来歴メタデータでは内部の保管先だけを中立表記へ置き換え、元と公開物それぞれのSHAを `PUBLICATION_MAP.json` へ記した。元の監査記録中のハッシュは当時の原物を指す。今回の配布物の照合には新しい `MANIFEST.json` を使う。公開用の再梱包全体は、数学本文の独立監査とは別に照合する。

応用例は外側の規則を明示した数学模型。現物の磁針の回転量や、背景の場方程式を満たす物理系は、次に調べる対象として残る。生成例を改変するときは、有理数実装の入力域を記した `INPUT_CONTRACT_JA.md` を先に読む。
