## P2：Bの有理数実装は、全ての有理成分の単軸入力を扱えない

対象：B/study/model.py:51 と b2.py:83。READMEの有限一歩・入力境界の説明に、算術上の受入条件が不足している。

次の二つは、成分が全て有理数のrank-one直交射影である。

```
P = diag(1,0,0)
Q = [[1/2,1/2,0],[1/2,1/2,0],[0,0,0]]
S = P-I/3
T = Q-I/3
```

両方ともa=1の単軸族で、tr(QP)=1/2>0。実数上ではz軸まわり45度の一意な最小回転が存在する。しかし `generated_link(S,T)` は次の例外で停止した。

```
ArithmeticError: This exact-rational test has no rational square root for the requested value
```

`sqrt(1/2)` をFractionで表せないためであり、幾何的に運搬が決まらないわけではない。固定された65検査の値や一般式を否定する反例ではない。

最小の対応は「この実行器は必要な平方根が有理数となる入力に限定する」と明記し、算術的な未対応を `Underdetermined` と分けて返すこと。一般の有理射影や実数入力まで受けるなら、代数的数または誤差管理を伴う別実装が必要。この監査では元コードを変更していない。

## 五つの依頼点への回答

### 1. Coreの規約・符号

圧縮は m2(u|v)=vu。内部挿入はΣTij e_j c e_i。対称跡なし残差上でA2(S)=-2Sとなる。九つのテンソル基底全てと四つの四元数プローブ基底を、対象実装とは別に書いたHamilton積で照合した。値・残差の再構成も一致した。

D=diag(1,-1,0)、Eのxy,yx成分を1とすると、[A2(E),A2(D)]=8Jz。反対称行列Kについてm2(K/2)の虚部がその回転軸ベクトルとなる符号も一致する。A/B間と固定Core原典の間に規約の反転は見つからなかった。

### 2. 生成式と最小性

P²=Pを微分するとP dotP P=0、(I-P)dotP(I-P)=0。したがってΩ=[dotP,P]は反対称で、[Ω,P]=dotP。これを満たす別の反対称生成子との差Zは[P,Z]=0を満たす。Ωは二部分空間を結ぶ成分、Zはその内部成分なので直交し、ノルム二乗が加算される。Frobenius最小性の証明は成立する。

S=a(P-I/3)の振幅微分は交換子から消え、[dotS,S]/a²=[dotA2,A2]/(4a²)。ただし、振幅が変わると追従するのはPである。S全体なら

```
dotS = (dot a/a) S + [Omega,S]
```

であり、純粋な回転だけで振幅変化を運ぶことはできない。次版で「残差への追従」を仮定するときは、この区別を明示する必要がある。

有限一歩は、符号を揃えた単位軸n,mについて二つの平面反射の積を独立に構成して照合した。応答交換子や提出側のRodrigues関数をオラクルとして再使用していない。24組で完全一致。変動振幅・符号、連続生成子、余分なひねりによるノルム増加も24組で厳密に確認した。

「最小」は各連続生成子、または指定した短い射影弧に関するもの。疎な端点列から真の連続経路を復元した、経路全体の未知の作用を最小化した、という主張には拡張できない。

### 3. 反例の前提と結論の強さ

同じ残差を保つ非自明なひねりが荷物の応答を変える例は正しい。これは追従条件だけの一意性を否定する。最小ノルムを追加した後の一意性を否定するものではない。

独立な端点フレームについて、入力を変えない終点stabilizer Hがあると、同じ入力に対してFとHFが要求される。可逆なFならF=HFはH=Iを意味するため矛盾。この証明も成立する。単値・可逆な具体的接続を要求する範囲の障害であって、商類・多価・非可逆な出力や参照データを許した構成まで否定しない。

追加の小例では、S=diag(1,-1,0)のように三固有値が異なっていても、H=diag(-1,-1,1)はSを保つ。この障害は単軸の連続stabilizerだけに依存しない。「一般残差なら必ず解消する」とは言えない。

### 4. 表し方の変更と実作用

荷物・プローブ・測定方向を一緒に回せば応答は不変。荷物だけを回せば共通測定への応答が変わる。この二つを別々の厳密検査にした。

Bの提出検査は、元の参照接続Iを各局所フレームへ変換する場合を扱っていた。監査ではさらに、元から非自明な参照回転B0と独立した始点・終点フレームを24組与え、R'=Gt R Gs^Tとの一致を確認した。参照接続の変換を含む共変性が、恒等参照の例だけに依存していないことを確認した。

Aは保存されたグラフを独立なHamilton積で読み直し、途中挿入±24/25、後付け一致を再現した。別のi|iとk|k、別の共通プローブでは±120/169となった。一方、異なる残差でも一つの選んだプローブで同じ結果になる対照も確認した。Coreの完全性は応答演算子全体についてであり、単一スカラー読出しの完全性ではない。

### 5. 報告と実装範囲

Aの「指定接続をB2へ外側で結ぶ」、Bの「順序付き経路・比較枠・最小ひねりを追加した条件付き生成」という限定は、実装と整合している。入力から辺回転を計算する機能は実装されているが、どの経路を入力するか、なぜそのひねり規則を選ぶかは別の選択として残る。

## 新しい小例：閉じた軸は、向き付きベクトルの帰還を保証しない

監査用の軸表示を

```
(1,0,0) → (3/5,4/5,0) → (-3/5,4/5,0) → (-1,0,0)
```

として、その射影から作った残差だけを生成器へ与えた。隣接する軸の重なりは非零で、最初と最後の残差は同じ。生成された全回転は厳密にdiag(-1,-1,1)だった。

これは射影の閉路であり、連続な向き付き軸は反転している。閉路の全回転が始点の向き付き軸を必ず固定する、あるいは必ずその軸まわりのSO(2)回転になる、という拡張はできない。提出された三角形の結果への反論ではなく、今後の定理の仮定を確認するための別例である。
