# 保持・更新・経路読出しの見取り図

この研究列の問いは、**いま同じ状態に見える二つの入力が、次の指定操作でも同じ応答を返すか**である。後続操作で差が出るなら、その差を保存する最小の状態を求める。

## 共通の原理

生の入力空間を \(E\)、現在の観測を \(q:E\to Y\)、追加で支えたい操作の出力を \(F:E\to Z\) とする。必要十分な保持状態は

\[
E/(\ker q\cap\ker F)\cong\operatorname{im}(q,F).
\]

追加保持量は \(\operatorname{rank}(q,F)-\operatorname{rank}q\)。この一般原理を、自由数の具体的な挿入・係数読出し・二経路比較へ適用したのが Notes 27 以降である。

「最小」は、指定した入力空間と観測・操作族に対する最小性を意味する。操作族を増やせば、必要な保持量も変わり得る。

## 1296と1152を区別する

Note 30 の記号で、\(P_{ab},P_{ba}\) は二つの生の経路、\(q\) は終点観測、\(R_b\) は両経路に共通のgap 5係数読出しである。

| 条件 | なお変化できる読出し情報 |
|---|---:|
| 二経路の粗い終点が一致：\(qP_{ab}x=qP_{ba}x\) | 差 \((R_bP_{ab}-R_bP_{ba})x\) の像は1296次元 |
| 五つの観測 \(H_5=(S,M_a,M_b,F_{ab},F_{ba})\) を固定 | \(N=R_bP_{ba}\) の不定部分 \(N(\ker H_5)\) は1152次元 |

後者では読出し先のcoreが1296次元なので、商として144次元が既存の観測から決まる。これは \(1296-1152\) であり、前者の終点一致だけを課した場合とは条件が異なる。

## 今回の節目：144次元の正体と読出し則

Note 31は、この商と元のcoreを、具体的な同型

\[
\Psi:T_{212}\xrightarrow{\sim}T_R/W
\]

で結ぶ。\(W\) は1152次元の読出し不定部分。対応は、二つの新入力に回転不変のスカラー成分 \(\eta=\frac13\sum_r e_r\otimes e_r\) を与え、終点の和をゼロにした入力から構成される。入力の代表を変えても同じ商の値になる。

さらに、\(Sx=c\otimes a\otimes b\)、\(c\in T_{212}\) の場合、読出しの確定部分は

\[
\boxed{\Psi^{-1}([Nx])=\langle a,b\rangle c+
\Lambda_{\mathrm{sym}}\bigl((F_{ab}+F_{ba})x\bigr).}
\]

**元のcoreに新入力二つの内積を掛けた項と、二つの終点の和から来る項が、確定する読出しを与える。** 後者の写像 \(\Lambda_{\mathrm{sym}}:T_{232}\to T_{212}\) は全射である。

共通始点と終点の和の保持量は2628次元であり、そこへ全読出しを加えると3780次元となる。五つの観測をすべて残す場合と、読出しに残る不定部分は同じ1152次元である。この区別により、保存する履歴全体と、特定の読出しを決める情報を分けて設計できる。

27〜31はここで一つの研究単位になる。**必要な保持量を求める → 消えた差を再検出する → 次の操作で必要量が増える → 経路差を比較する → それでも共通に決まるcoreと読出し則を取り出す。**

## 最初の隣接：読出し則を保つ輸送

Note 32では、隣接する配置列

\[
(122,132,142)\longrightarrow(212,222,232)
\]

を、動かない右外辺で比較する。この共通辺から、144・432・1296次元のcore同型 \(J_0,J_1,J_2\) が一意に決まる。挿入と後続読出しは同じ実際のgapに固定する。

隣接側を \(n\)、元の側を \(o\) と書き、読出し先の輸送を \(J_R=J_1\otimes I\) とすると、

\[
J_R(W_n)=W_o,\qquad
\bar J_R\Psi_n=\Psi_oJ_0,\qquad
\Lambda_oJ_2=J_0\Lambda_n.
\]

**1152次元の不定部分がそのまま運ばれ、確定する144次元の読出し則も一致する。** この指定した比較では、確定するcoreを運ぶための追加保持量はゼロである。六つのmatching商と二経路・読出しを最初から再構成し、二つの可換性の欠陥が厳密にゼロであることを検証した。

この一辺での整合を、Note 33で四配置の閉路へ広げた。

## 閉路：二つの道で同じ読出しへ至る

四配置の間で、二つの内部頂点を動かす順序を入れ替える。各辺の輸送は、動かない外辺の応答からそれぞれ独立に決める。

| 段階 | 閉路 | coreの一周後 |
|---|---|---|
| 挿入前 | \(122\to131\to221\to212\to122\) | \(I_{144}\) |
| 一回挿入後 | \(132\to141\to231\to222\to132\) | \(I_{432}\) |
| 二回挿入後 | \(142\to151\to241\to232\to142\) | \(I_{1296}\) |

**三段ともcoreが元に戻り、四辺すべてで読出し商と終点項の可換性が成立する。** したがって、このcellでは144次元の確定部分をどちらの道で運んでも同じになり、1152次元の不定部分も保たれる。確定部分の輸送に必要な追加保持量はゼロ。

十二のmatching商と四配置の二経路・読出しを再構成し、三つの閉路差と八つの読出し則の欠陥が厳密にゼロとなることを検証した。Note 30の挿入順序による応答差と、今回の配置輸送の経路独立性は、それぞれの指定操作に対する結果として並立する。

次は、更新を支える最小保持状態そのものへ輸送を持ち上げる。保持情報をどう運ぶかを定め、先に更新してから運ぶ場合と、先に運んでから更新する場合の整合を調べる。

## 残っている研究の枝

- **許容操作族の閉性。** Note 27には有限の操作グラフで安定核を求める一般手続きがある。自由数の拡大し続ける配置・操作族に対する具体的な安定化と保持量が次の問題となる。
- **内部輸送の全体像。** 三つ以上の内部spectatorsを持つ配置網を揃え、各写像が保存する構造と経路比較を統一する。
- **全長の生成・完全性。** 全 \(n\) の四面体生成とmiddle exactnessへの一般化を進める。
- **閉路と合流性。** Note 33で最初の配置cellと読出し則の整合が確定した。配置網を広げ、更新を含む操作系の文脈的局所合流性へ接続する。Note 30の二経路差と、追加比較操作による生の一致は、それぞれ別の等式として保持する。
- **局所公式。** 大きな行列で確定した写像を短い四元数応答式へ縮め、再利用・実装しやすくする。
